# ログビューア

Pythonの標準ライブラリだけで動く、ローカルPC用のログビューアです。

## 起動

```powershell
python app.py
```

ブラウザが自動的に開きます。開かない場合は http://127.0.0.1:8000 にアクセスしてください。

1. 「ファイルを選択」でWindows標準のファイル選択ダイアログを開き、任意のフォルダ・ドライブからログファイルを選択します。キャンセル時は現在の選択を維持します。絶対パスの直接入力もできます。
2. 「最大行数」で表示する末尾の行数を指定します。初期値100行、範囲1～10,000行です。
3. 約1秒ごとにファイルを読み直して更新します。「一時停止」や「末尾に追従」の解除もできます。

文字コードはUTF-8、Shift_JIS（CP932）、UTF-16を選択できます。ファイルの削除・読み取り失敗は画面に表示し、再作成されると自動で読み取りを再開します。ファイルの短縮・置き換えにも追従します。

1回の読み込みは末尾4 MiBまでです。上限を超える長い行などでは指定行数より少なくなる場合があり、画面に表示します。改行されていない末尾も表示します。

ダイアログのアドレス欄では `D:\logs` やネットワーク共有のパスも指定できます。選択対象はPythonを起動したPCからアクセスできるファイルです。ダイアログにはPython標準のTkinterが必要です（Windows版Pythonには通常同梱されています）。サーバーはローカル接続（127.0.0.1）だけを受け付けます。

```powershell
python app.py --port 8080 --no-browser
python -m unittest -v
```

終了するには起動したターミナルで Ctrl+C を押します。
